# Feature map

Each row links a user-facing capability to its route, its entry files and the selectors, ids and ARIA attributes that tests and assistive technology rely on.

The site defines no custom keyboard shortcuts. Keyboard use follows the native behaviour of links, buttons, forms, `<details>` and `<dialog>`.

| Capability | Route | Entry files | Selectors, ids and ARIA | Keyboard |
| --- | --- | --- | --- | --- |
| Skip link | Every page | `src/app/layout.tsx` | `a[href="#main-content"]`, visible on focus | First Tab, then Enter, jumps to the page content |
| Header and primary navigation | Every page | `src/components/layout/header.tsx`, `src/components/layout/nav-link.tsx` | `header`; `nav[aria-label="Main navigation"]` on large screens; the current page link has `aria-current="page"` | Tab through the links in order; Enter follows a link |
| Start a project button | Every page | `src/components/layout/header.tsx`, `src/components/layout/mobile-nav.tsx` | Button link to `site.cta.href` (`/contact`); desktop header and inside the mobile menu | Tab, then Enter |
| Mobile menu | Every page, on small screens | `src/components/layout/mobile-nav.tsx` | Menu button with `aria-controls="site-menu"`, `aria-expanded` and `aria-haspopup="dialog"`; `dialog#site-menu` labelled "Site menu"; `nav[aria-label="Mobile navigation"]`; Close button inside `form method="dialog"` | Enter or Space opens the menu and moves focus into it. Escape or Close menu closes it and returns focus to the Menu button. Choosing a link closes it. |
| Footer | Every page | `src/components/layout/footer.tsx` | `footer`; `nav[aria-label="Footer navigation"]`; postal address in `address`; mailto link to `site.email`; no social links | Tab through the links |
| Home page | `/` | `src/app/page.tsx`, `src/components/home/` | `main#main-content`; one `h1` in the hero; sections labelled by `aria-labelledby` (`hero-title`, `capabilities-title`, `work-title`, `how-title`, `standards-title`, `stack-title`, `cta-title`); tools list `aria-label="Tools we use in production"`, with the duplicate marquee copy `aria-hidden` | Tab through the buttons and links. The tools ticker has no focusable items. |
| Work index | `/work` | `src/app/work/page.tsx`, `src/components/work/` | `main#main-content`; each case study is an `article[aria-labelledby="{slug}-name"]` with a "Read the case study" link and an external link to the live site | Tab through the case study links |
| Case study | `/work/[slug]` | `src/app/work/[slug]/page.tsx`, `src/components/work/` | `h1#case-study-name`; screenshots carry `alt` text and only the browser chrome around them is `aria-hidden`; sections `#challenge-heading`, `#built-heading`, `#related-capabilities-heading`; "Visit" button and app or related links open in a new tab and say so to screen readers | Tab through the links |
| Case study social preview | `/work/[slug]/opengraph-image` | `src/app/work/[slug]/opengraph-image.tsx` | 1200 by 630 PNG with the name, sector and summary; unknown slugs return 404 | None |
| Services index | `/services` | `src/app/services/page.tsx`, `src/components/services/` | `#services-heading`; capability list `aria-label="Capabilities"`; each capability title is an `h2`, followed by an "in detail" link to its page; engagement models `#work-together-heading` | Tab through the "in detail" links |
| Service detail | `/services/[slug]` | `src/app/services/[slug]/page.tsx`, `src/components/services/` | `#deliverables-heading`, `#stack-heading`, `#related-work-heading`, `#faq-heading`, `#other-capabilities-heading`, `#services-cta-heading`; unknown slugs return 404 | Tab through the links |
| Service FAQ | `/services/[slug]` | `src/components/services/capability-faq.tsx` | `#faq-heading`; native `details` and `summary`, with each question as an `h3` inside its `summary` | Enter or Space on a question opens or closes its answer |
| About | `/about` | `src/app/about/page.tsx`, `src/components/about/` | `h1#about-heading`; sections `#story-heading`, `#principles-heading`, `#process-heading`, `#stack-heading`, `#leadership-heading`, `#cta-heading`; the company address in `address` | Tab through the links |
| Contact form | `/contact` | `src/app/contact/page.tsx`, `src/app/contact/actions.ts` (Server Action `submitContactEnquiry`), `src/components/contact/enquiry-form.tsx` | `form[aria-labelledby="enquiry-heading"]`; fields `#enquiry-name`, `#enquiry-email`, `#enquiry-company`, `#enquiry-need`, `#enquiry-budget`, `#enquiry-message`; errors `#enquiry-<field>-error`, linked with `aria-describedby`, and `aria-invalid="true"` on the field; honeypot `input[name="website"]` hidden with `aria-hidden` and `tabindex="-1"`; `role="status"` live region; `SubmitButton` uses `useFormStatus` | Tab moves through the fields in order, and the honeypot is skipped. Enter in a text field submits. After an invalid submit, focus moves to the first invalid field. After a sent or not-sent result, focus moves to the result. |
| Contact states | `/contact` | `src/components/contact/enquiry-form.tsx`, `src/components/contact/state.ts`, `src/components/contact/submit-button.tsx` | Idle, with no status. Invalid: "Check the highlighted fields. Nothing was sent." Pending: the button reads "Sending…" and is disabled. Sent: `h2` "Thanks. We have your message." Not sent, for missing delivery settings, a failed delivery or a rejected submission: a plain statement, an "Email us instead" link with a prefilled mailto, and a link to `site.email`. | Same as the form. Focus moves to the confirmation or the not-sent notice. |
| Direct contact details | `/contact` | `src/components/contact/contact-details.tsx` | `aside[aria-label="Contact details"]`; mailto link to `site.email`; postal address in `address`; the "What happens next" steps in an ordered list | Tab to the email link |
| Not found | Any URL without a page, or a `notFound()` call | `src/app/not-found.tsx` | `main#main-content`; one `h1`; `nav[aria-label="Helpful links"]` with Home, Work, Services and Contact | Tab through the four links |
| Error recovery | Errors inside a page | `src/app/error.tsx` | `main#main-content`; one `h1`; "Try again" calls `unstable_retry`; "Back to home" link; error reference shown when Next supplies one; mailto link to `site.email` | Tab to Try again, then Enter retries |
| Root error fallback | Errors in the root layout | `src/app/global-error.tsx` | Standalone `html` and `body` with inline styles; `main#main-content`; "Try again" button | Tab to Try again, then Enter retries |
| Legacy service links | `/services/<old-slug>` | `next.config.ts` (`redirects()`), `src/content/services.ts` (`legacyServiceRedirects`) | Permanent 308 redirect to the matching `/services/<capability>` | None |
| Site social preview | `/opengraph-image`, `/twitter-image` | `src/app/opengraph-image.tsx`, `src/app/twitter-image.tsx` (re-exports the Open Graph file); every page points its share card here through `src/lib/metadata.ts` | 1200 by 630 PNG with the wordmark and tagline, generated at build | None |
| Sitemap | `/sitemap.xml` | `src/app/sitemap.ts` | Home, work, services, about, contact, and each case study and capability, as absolute URLs under `site.url` | None |
| Robots | `/robots.txt` | `src/app/robots.ts` | Allows all crawlers; sitemap and host set from `site.url` | None |
| Structured data | Every page | `src/components/seo/structured-data.tsx`, mounted in `src/app/layout.tsx` | `script[type="application/ld+json"]` with Organization and WebSite | None |
| Analytics | Every page, when configured | `src/components/analytics.tsx` | Loads only when `NEXT_PUBLIC_GA_MEASUREMENT_ID` is set | None |
| Focus and motion | Every page | `src/app/globals.css` | Gold `:focus-visible` outline with a 2px offset; `prefers-reduced-motion` turns animation off | Focus stays visible on every control |
